# FlowTrim demo package

Everything needed to show and test the full chain without routers or a tenant:

```
flowgen replay ──UDP──► FlowTrim ──HEC/HTTPS──► Falcon Onum (mock) ──HEC──► Falcon NG-SIEM (mock)
```

Run it: `./demo/run-demo.sh`, then open http://127.0.0.1:9109.

## Sample captures (`samples/`)

| File | Protocol | Flows | Re-exports | Duration | Open in Wireshark |
|---|---|---|---|---|---|
| `enterprise-mix.ipfix.pcap` | IPFIX (v10), IPv4 + IPv6 templates | 78,030 | 23,873 | 60 s @ 1,300/s | ✅ decode UDP 4739 as CFLOW |
| `campus.v9.pcap` | NetFlow v9 | 24,015 | 7,003 | 30 s @ 800/s | ✅ decode UDP 4739 as CFLOW |
| `branch.v5.pcap` | NetFlow v5 | 15,015 | 3,023 | 30 s @ 500/s | ✅ |

Each capture has a `.json` **manifest** with the ground truth: the count per traffic pattern, and which FlowTrim rule should catch each one. Use it to check that a run did what you expected.

| Pattern | Share | What FlowTrim should do |
|---|---|---|
| `east_west_api_chatter` (10.1.x → 10.2.0.10:443) | 40% | **Rollup**: one record per conversation per window |
| `dns_to_corp_resolvers` (→ 10.0.0.53:53) | 15% | **Drop** (`dns_to_corp_resolvers`), counted in `drop_summary` |
| `ntp_to_corp_servers` (→ 10.0.0.123:123) | 7% | **Drop** |
| `mdns_multicast` (→ 224.0.0.251) | 8% | **Drop** (`multicast_broadcast`) |
| `internal_smb_ssh_sweep` (10.1.9.9 → 10.3.0.0/24 :445/:22, SYN-only) | 3% | **Bypass** (lateral ports), plus one **fanout_summary** per window |
| `threat_intel_destination` (→ 198.51.100.7:8443) | 0.5% | **Bypass** (intel list), threat tag, severity raised |
| `denied_inbound` (internet → 10.1.0.20:3389, SYN-only) | 1% | **Raw**: inbound traffic is never rolled up. NetFlow/IPFIX here carry no firewall action, so the `denied_traffic` bypass applies to firewall and AWS VPC exports that do. |
| `beacon_c2_candidate` (10.1.5.5 → 203.0.113.66:443 every 2 s) | — | **Rollup** with `iat_ms.mean ≈ 2000`, `stddev ≈ 0` |
| `web_egress` (+ `web_egress_ipv6`) | ~26% | Mostly raw. Repeated pairs roll up. |
| Second router `192.0.2.2` re-exporting ~30% of packets | — | **Dedup** |

All addresses are private, documentation (RFC 5737 / RFC 3849) or demo ranges.

## Replay into a real receiver

```bash
bash <<'FLOWTRIM_REPLAY_REAL'
set -euo pipefail
REPO="$HOME/src/flowtrim"
cd "$REPO"
export REAL_HEC_URL="https://<onum-listener-or-ngsiem-connector-url>"
export REAL_HEC_TOKEN="<token>"
./demo/run-demo.sh
FLOWTRIM_REPLAY_REAL
```

## Make your own captures

```bash
bash <<'FLOWTRIM_MAKE_SAMPLE'
set -euo pipefail
cd "$HOME/src/flowtrim"
go run ./cmd/flowgen gen -format ipfix -rate 2000 -duration 120s -fast -send=false -seed 42 \
  -pcap /tmp/my-sample.pcap -manifest /tmp/my-sample.json
echo "wrote /tmp/my-sample.pcap and /tmp/my-sample.json"
FLOWTRIM_MAKE_SAMPLE
```

`flowgen replay` also plays **real** captures (classic pcap, Ethernet or raw IP, IPv4 or IPv6) and shifts v5/v9/IPFIX timestamps to "now" (`-retime`, on by default). Convert pcapng first with `editcap -F pcap in.pcapng out.pcap`.
